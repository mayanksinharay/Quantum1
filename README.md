# Quantum Computing Basics with Qiskit

## Overview

This project is an introductory exploration of **Quantum Computing using Qiskit**.
The notebook demonstrates fundamental concepts of quantum mechanics and quantum computation through practical Python examples using the Qiskit framework.

The project covers:

* Quantum state vectors
* Matrix and vector operations
* Quantum gates
* Quantum measurements
* Quantum circuit visualization
* Probability distributions in quantum systems

This notebook is designed for beginners who want hands-on exposure to quantum computing concepts using Python.

---

## Technologies Used

* Python
* NumPy
* Qiskit
* Matplotlib
* SymPy
* Jupyter Notebook

---

## Features

### Quantum State Representation

* Creation of qubits using vectors
* Validation of quantum states
* Visualization of quantum states in LaTeX format

### Matrix Operations

* Matrix-vector multiplication
* Quantum operator transformations
* Basic linear algebra for quantum systems

### Quantum Gates

Implementation and visualization of common quantum gates:

* Hadamard Gate (H)
* Pauli-Y Gate (Y)
* Phase Gate (S)
* T Gate (T)

### Quantum Measurement

* State measurement simulation
* Post-measurement state analysis
* Probability sampling

### Quantum Circuit Visualization

* Building quantum circuits using Qiskit
* Circuit rendering using Matplotlib
